设计输入：应用层给定，不可协商

| 项                 | 值               |
| ----------------- | --------------- |
| 最大探测距离 $R_{max}$​ | $1 km$          |
| 目标                | 漫反射， $\rho=0.1$ |
| 测距精度              | $10 cm (1σ)$    |
| 检测概率  $@ R_{max}$ | $P_D \ge 99\%$  |
| 虚警率               | ≤ 1 次/小时        |
| 最近距离 $R_{min}$    | $2 m$           |
其余全部是推导结果。
共有三条路径：

![[dTof接收前端-1788089396891.webp]]


唯一耦合的是带宽进入了噪声链： $\sigma_{in} = S_{i}\sqrt{B_n}$  ，增益链完全独立(与动态范围有关)

##### 第一步：预算 $I_{min}$ 
选定发射端（这些是根据设计做出的选择）：

|          参数           |   值    |
| :-------------------: | :----: |
|          波长           | 905 nm |
|      峰值功率 $P_t$       | 800 W  |
|        脉宽 FWHM        | 10 ns  |
|        接收口径 D         | 75 mm  |
|  光学效率 $\eta_{opt}$​   |  0.7   |
| 双程大气透过率 $\eta_{atm}$  |  0.91  |
| APD 响应度 $\mathcal{R}$ | 5 A/W  |
朗伯目标回波功率：

$$
P_r = P_t \cdot \rho \cdot \frac{A_r}{\pi R^2} \cdot \eta_{opt} \cdot \eta_{atm}
$$

$A_r = \pi (0.0375)^2 = 4.42 \times 10^{-3} \, m^2$  这个应该是计算接收器的有效面积

$$
P_r = 800 \times 0.1 \times \frac{4.42\times 10^{-3}}{\pi \times 10^6} \times0.7\times0.91 = 71.6nW
$$

得到最小电流：

$$
I_{min} = \mathcal{R} \cdot P_r = 71.6n W \times 5 A/W = 385nA
$$

##### 第二步：脉宽 → 带宽
脉冲 10%–90% 上升时间： $t_r = 0.76  \times FWHM = 7.16ns$ 

$$
BW_{min} = \frac{0.35}{t_r} = 48.9MHz
$$

若留有余量的话，取 $BW = 60MHz$ ， 噪声等效带宽 (二阶，一般来说一阶就够用了)

$$
B_n = 1.11 \times 60MHz = 66.6MHz
$$

>[!note] 带宽是双向的约束 
>低了压上升沿、加大行走误差；高了噪声按 $\sqrt{B_n}$​ 涨。48.9 MHz 是下限，不是目标值。

##### 第三步：虚警要求 → 门限 $k$ 
无模糊距离窗：

$$
T_w = \frac{2 R_{mqx}}{c} = 6.67 \mu s \Rightarrow f_{rep} \leq \frac{1}{T_w} = 150kHz  
$$

窗口独立样本数：

$$
N = 2B_n T_w = 2 \times 66.6MHz \times 6.67\mu s = 888
$$

取 $f_{rep} = 100kHz$ ，每小时窗口数 $= 10^5 \times 3600 = 3.6\times10^8$ ，故：

$$
\begin{gather}
P_{FA,窗} = \frac{1}{3.6\times 10^8} = 2.78 \times 10^{-9} \\[4pt]
Q(k) = \frac{P_{FA,窗}}{N} = \frac{2.78 \times10^{-9}}{888} = 3.13 \times 10^{-12}\\[4pt]
\boxed{k = Q^{-1}(3.13 \times^{-12}) = 6.87}
\end{gather}
$$

 $P_{FA,窗}$  就应该是1小时发生一次的概率。 Q(k)的计算 [[SNR的关系.md#^87185f]] 

##### 第四步：检测概率 → $d$ 
 $P_D = 99\%$  要求余量 $d - k = -Q^{-1}(0.99) = 2.33$ 

$$
\boxed{d = 6.997 +2.33 = 9.2}
$$

这个d就是 $A/\sigma$  的值。

##### 第五步：噪声预算

$$
\begin{gather}
\sigma_{in} \leq \frac{I_{min}}{d} = \frac{358nA}{9.20} = 38.9nA rms\\[4pt]
S_{i,tot} \leq \frac{\sigma_{in}}{\sqrt{B_n}} = \frac{38.9n A}{\sqrt{66.6\times10^6}} = 4.77pA/\sqrt{Hz} 
\end{gather}
$$


==功率分配（RSS）：==

| 来源                               | 预算                  | 占比   |
| -------------------------------- | ------------------- | ---- |
| APD 散粒噪声（背景光 + 暗电流，含倍增噪声因子 FF F） | $2.5 pA/\sqrt{Hz}$  | 27%  |
| **TIA 输入参考噪声**                   | $4.06 pA/\sqrt{Hz}$ | 73%  |
| 合计 RSS                           | $4.77 pA/\sqrt{Hz}$ | 100% |

$$
\boxed{S_{i,TIA}\leq 4.0pA/\sqrt{Hz}} 
$$

这是 TIA 设计的硬指标。

##### 第六步：跨阻增益（摆幅决定）
最高增益档要求：最小信号 $I_{min}$​ 时输出足够让比较器工作，最大信号不饱和。
设该档饱和电流 $10\ \mu$A，输出摆幅 1V：

$$
Z_{T} = \frac{1V}{10 \mu A} = 100k\Omega = 100dB\Omega
$$

自洽性校验：

| 量                         | 计算                               | 值                   |
| ------------------------- | -------------------------------- | ------------------- |
| $V_{sig}​ @ I_{min}$      | $358\text{nA}\times100\text{k}$  | $35.8 mV$           |
| $\sigma_{out}$​           | $38.9\text{nA}\times100\text{k}$ | $3.89 mV$           |
| $门限 V_T = k\sigma_{out}$​ | $6.87\times3.89mV$               | $26.7 mV$           |
| 检测余量                      | $35.8-26.7 = 9.1mV$              | ==$2.34\sigma  ✓$== |

==余量 2.34σ 与第 4 步的 2.33 吻合，闭环成立。==

**全量程动态范围**：

$$
\frac{I_{max}}{I_{min}} = (\frac{R_{max}}{R_{min}})^2 = (\frac{1000}{2})^2 = 2.2\times10^5
$$

远超单档 29 dB，故需增益分档：

| 档位  | $Z_T$​  | 输入范围       |
| --- | ------- | ---------- |
| 高   | 100 dBΩ | 0.36–10 µA |
| 中   | 80 dBΩ  | 10–100 µA  |
| 低   | 60 dBΩ  | 0.1–1 mA   |
| 最低  | 46 dBΩ  | 1–5 mA     |

##### 第 7 步：输入阻抗
计算信号带宽处的容抗：设 $C_{in} = C_{APD} + C_{pad} + C_{gs} \approx 2pF$ 

$$
\left| Z_C\right| = \frac{1}{2\pi 60MHz \times 2 pF} = 1327 \Omega
$$

要求 $90\%$ 以上注入 TIA：

$$
R_{in} \leq = \frac{\left| Z_C\right|}{10} = 133 \Omega \Rightarrow \boxed{设计目标 R_{in} < 50\Omega} 
$$
输入极点： $f_p = \frac{1}{2\pi \times 50 \times 2pF} = 1.59GHz \gg 60MHz ✓$
