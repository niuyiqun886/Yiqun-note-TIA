| A4 | TIA 拓扑 | | CG · RGC · shunt-shunt FB · inverter · 有源反馈 |
| A5 | 跨阻增益 $Z_T$ | | dBΩ　**⚑ 前端单级还是整链（Q24）** |
| A6 | 带宽 BW (−3dB) | | MHz　**⚑ 电学还是光学** |

### B 组 —— 自己算（判断力全部来自这一组）

| 列 | 派生量 | 算法 | 值 | 它告诉你什么 |
|---|---|---|---|---|
| B1 | 跨阻带宽积 | $Z_T[\Omega]\times BW[\text{Hz}]$ | | 拓扑能力的直接度量，同工艺有天花板 |
| B2 | 带容量归一 | $Z_T\times BW\times C_{in}$ | | 扣掉「用小 PD 作弊」的成分 |
| B3 | 功率效率 | $Z_T\times BW / P$ | | 谁在用电换性能，谁有结构性改进 |
| B4 | 噪声自洽 | $I_{n,rms}$ vs $i_{n,in}\sqrt{B_n}$ | | 对不上 → 噪声不平坦或口径有问题 |
| B5 | 灵敏度反推 | 由 A7 + A13 反推 MDS | | 跟它宣称的 MDS 对，这是 Q17 的默认选项 |

## 八、每读完 5 篇：复盘（60 min）

1. 总表按 **B1** 排序，画散点：x = BW，y = $Z_T$，点大小 = 功耗，颜色 = 拓扑
2. **找边界**——哪两列之间过不去。那条线就是这个领域当前的物理极限
3. 写三行：
   - 这个极限是什么：
   - 突破它的手段有哪几种：
   - 还没人试过的是什么：　← **选题来源**
4. 清疑问池：划掉已自动解决的，剩下的才是真问题，这时候再集中查

---

> **停止条件**：当你能提前猜到下一篇的贡献时，停止读、开始动手。通常在第 6–8 篇。剩下的转为按需查——做设计撞到问题时带着问题回去翻，半小时的收获超过现在读一整天。
>
> **最终判据**：看到一组指标，你能立刻说出「这个数是硬的、那个数是选口径选出来的、这两个数不可能同时成立」。做得到就是读到位了。
